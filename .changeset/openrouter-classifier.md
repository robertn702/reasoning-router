Add the OpenRouter classifier (`provider: "openrouter"`), which calls any OpenRouter decision model through OpenRouter's Decisions API (`https://openrouter.ai/api/alpha/decisions`) with the System One request. `apiKey` (an OpenRouter key) and `model` (an OpenRouter decision model ID, such as `typesafe/jev-1.13`) are required.
