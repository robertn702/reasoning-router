# 평가

[English](README.md) | [简体中文](README_CN.md) | [日本語](README_JA.md) | 한국어

분류기로 라우팅한 추론 수준은 고정 추론 수준보다 추론을 덜 쓰면서도 해결률을 유지할까요? 이 보고서들은 [SWE-bench Verified](https://huggingface.co/datasets/SWE-bench/SWE-bench_Verified)의 실제 코딩 작업으로 이를 측정합니다. 각 시도는 새로운 체크아웃에서 코딩 에이전트를 실행한 뒤, 공식 SWE-bench 테스트 하네스로 결과를 채점합니다.

## 주요 결과

테스트한 GPT-6 Astra 작업 구성에서, Jev로 라우팅한 추론 수준과 고정 `high` 추론 수준은 각각 **44/44회 시도**를 해결했습니다. Jev는 시도당 입력 토큰을 **20% 적게**, 출력 토큰을 **14% 적게**(추론 포함), 시간을 **9% 적게** 사용했습니다.

![핵심 비교: 두 arm 모두 44건 중 44건을 해결했으며, Jev는 고정 high 대비 평균 입력이 20.2%, 출력이 14.3%, 시간이 8.7% 더 적습니다.](results/router-core-comparison.svg)

이는 하나의 모델, 하나의 분류기, 작은 작업 집합에 대한 결과입니다. 일반적인 워크로드에 대한 추정치도, 해결률이 동일하다는 증명도 아닙니다. 이 수치를 인용하기 전에 [통합 보고서](results/router-consolidated-2026-09-25.md)를 읽어 보세요.

## 결과를 읽는 방법

- **Arm:** 각 작업은 고정 추론 수준(예: `medium`, `high`)과 분류기로 라우팅한 추론 수준(`jev`로 표기)으로 실행됩니다. 모델, 프롬프트, 기준 커밋, 타임아웃, 채점기는 arm 간에 고정됩니다.
- **Solved**는 SWE-bench 채점기의 판정입니다. **Evidence valid**는 해당 시도의 토큰 사용량이 완전히 기록되었음을 의미합니다. 토큰 평균은 evidence-valid 시도만 사용하므로, 비교하기 전에 분모를 확인하세요.
- **출력 토큰**에는 추론이 포함됩니다. 캐시된 입력은 입력의 일부이며 별도의 범주가 아닙니다. 토큰과 시간은 소비량 측정값이지 금액이 아닙니다.
- 메타데이터만 공개됩니다. 프롬프트, 패치, 트레이스, 채점기 로그는 하네스의 무시 대상인 `eval/runs/` 디렉터리에 남아 있습니다.

## 출처

모든 실행은 2026-09-23부터 2026-09-25 사이에 Jev를 사용해 이루어졌으며, 라우터가 이 저장소로 옮겨 오기 전의 것입니다. 따라서 보고서의 커밋 해시와 스크립트 경로는 그 이전의 것입니다. Jev 요청, Jev가 받는 대화 상태, 선택된 추론 수준을 모델 요청에 적용하는 방식은 `reasoning-router`에서도 변하지 않았습니다.
